Planned AI & Sync Features

Planned items for future development — prioritized as quick wins first.

  1. Realtime admin sync — push booking/create/update/delete events to all open admin clients (WebSockets).
  2. Offline client sync — local queue (IndexedDB) with retry and background sync when online.
  3. Two-way calendar sync — ICS export and optional Google Calendar integration (OAuth) for bookings.
  4. OCR auto-fill — improve license/ID parsing and auto-populate rental forms client-side or via server endpoint.
  5. Email/SMS notifications — confirmations, reminders, and alerts (SMTP/Twilio integration).
  6. Scheduled reminders — cron/job-queue driven reminders for pickups, returns, and maintenance.
  7. Admin chat assistant — an assistant that answers questions about bookings, fleet, and policies (LLM proxy).
  8. Auto-tagging & scoring — heuristic or ML-based risk scoring and automatic tagging of bookings.
  9. Dynamic pricing suggestions — demand-aware price recommendations and seasonal rules.
  10. Booking conflict detection — detection, alerts, and guided resolution for overlapping requests.
  11. Background job queue — reliable worker queue for async tasks (emails, sync jobs, exports).
  12. Live vehicle tracking — show vehicle positions on the map (WebSocket/MQTT ingest).
  13. Fleet telemetry ingest — ingest and store vehicle telemetry for analytics and geofencing.
  14. Channel connectors & reconciliation — adapters for Turo, Expedia, etc., with reconciliation logic.
  15. Webhooks & public API — allow external systems to receive booking events and push bookings in.
  16. Import/export (CSV, ICS) — bulk import/export for bookings, customers, and calendar feeds.
  17. Audit logs & versioning — record changes and allow simple rollback/conflict resolution.
  18. Offline-first mobile support — mobile web app with local-first UX and sync recovery.
  19. Push notifications (web/mobile) — browser push and mobile notifications for urgent alerts.
  20. Sync conflict resolution UI — a small UI for administrators to review and resolve sync conflicts.
